# Anuncios del menú de GBoy-JS (AliExpress Portals).
# Una línea por anuncio, con los campos separados por | :
#   nombre | enlace de afiliado | imagen | etiqueta | categoría
#
# - nombre: texto corto que verá el usuario (por ejemplo "Mando 8BitDo Micro").
# - enlace de afiliado: el enlace https://s.click.aliexpress.com/... de Portals.
# - imagen: URL https de la foto del producto (en el Centro de anuncios, o clic
#   derecho en la foto del producto → "Copiar dirección de imagen").
# - etiqueta (opcional): oferta o precio, por ejemplo "-40 %" o "Envío gratis".
# - categoría (opcional): "mando" hace que salga primero en «Mando y teclado».
#
# Se muestran hasta 6 por vez, empezando por los que el usuario lleva más tiempo
# sin ver. Las líneas que empiezan por # se ignoran. Ejemplo:
# Mando Bluetooth 8BitDo | https://s.click.aliexpress.com/e/_XXXXXXX | https://ae01.alicdn.com/kf/XXXX.jpg | -35 % | mando
